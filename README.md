# あっち向いてホイ！

カメラで **指の向き** と **顔の向き** を判定して、CPU と対戦する「あっち向いてホイ」です。
ブラウザで開くだけで遊べます（インストール不要）。

## あそびかた

1. 回数（3・5・10回戦）、先攻・後攻、難易度、操作方法（カメラ／ボタン）を選んで「スタート！」
2. カメラ操作の場合、最初に「正面の顔」を登録します。顔や指を動かして、向きが正しく出るか試せます
3. 1回戦ごとに「攻め」と「守り」を1回ずつ交代で行います
   - **攻め**：「ホイ！」で人差し指を上下左右に向ける。CPU の顔が同じ向きなら 1点
   - **守り**：「ホイ！」で顔を上下左右に向ける。CPU の指と同じ向きだと CPU に 1点
4. 「ホイ！」より前に動くと **フライング** でやり直し
5. 制限時間内に向けないと、攻めは得点なし、守りは CPU の得点
6. 全部終わったとき、点数が多いほうの勝ち。連勝記録はブラウザに保存されます

| 難易度 | 制限時間 | CPU |
| --- | --- | --- |
| かんたん | 3秒 | 完全ランダム |
| ふつう | 2秒 | ときどき、あなたのクセを読む |
| むずかしい | 1秒 | ほとんど、あなたのクセを読む |

カメラが使えない端末や、カメラを許可しなかった場合は、ボタン（または矢印キー・W/A/S/D）で遊べます。
カメラの映像は端末の中だけで処理され、どこにも送信されません。

## GitHub Pages で公開する

カメラは `https` のページでしか動かないため、GitHub Pages で公開すると便利です。

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. **Build and deployment** の Source を **Deploy from a branch** にする
3. Branch で公開したいブランチ（例：`main`）と `/ (root)` を選んで **Save**
4. 数分後、`https://<ユーザー名>.github.io/attimuit/` で遊べるようになります

## 手元のパソコンで動かす

```sh
npm start        # http://localhost:8080 でゲームが開きます
npm test         # ルールと判定のテストを実行
```

`localhost` なら `https` でなくてもカメラが使えます。

## ファイルの構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の部品（タイトル・カメラ準備・試合・結果） |
| `style.css` | 見た目 |
| `src/main.js` | 画面の切り替えと試合の流れ |
| `src/game.js` | ルール・得点・CPU の考え方・記録 |
| `src/gesture.js` | 顔や手の点の位置から、上下左右を判定する計算 |
| `src/camera.js` | カメラの起動と、[MediaPipe](https://ai.google.dev/edge/mediapipe/solutions/guide)（Google の顔・手認識）での解析 |
| `src/sound.js` | 効果音 |
| `tests/` | `game.js` と `gesture.js` のテスト |

判定の感度を変えたいときは `src/gesture.js` の `FACE_THRESHOLD`、制限時間や CPU の強さは `src/game.js` の `DIFFICULTIES` を調整してください。
